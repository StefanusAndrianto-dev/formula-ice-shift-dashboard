# Formula ICE Shift Dashboard

ESP32-based real-time RPM monitoring and smart shift light dashboard system for Formula-style ICE vehicle applications.

## Features
- Real-time RPM simulation
- Smart racing shift light
- Engine performance status
- OLED motorsport dashboard
- LED bar RPM indicator
- Digital twin simulation using Wokwi

## Components
- ESP32 DevKit V1
- SSD1306 OLED Display
- LED Bar Graph
- Potentiometer
- 220Ω Resistors

## Development Environment
- Wokwi Simulator
- VS Code
- PlatformIO

## Simulation Purpose
This project simulates a motorsport dashboard instrumentation system commonly used in Formula-style ICE vehicles to assist drivers with RPM monitoring and optimal gear shifting.
